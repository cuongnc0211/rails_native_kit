# rails_native_kit

Claude Code plugin for Rails developers building and shipping mobile apps.

## Skills

- **hotwire-native** — iOS/Android with Hotwire Native: path configuration, bridge components, native screens, push notifications. Includes verified real-world gotchas for hotwire-native-ios 1.2.2.
- **kamal** — Zero-downtime deployment with Kamal 2: deploy.yml setup, secrets, accessories, troubleshooting.

## Installation

```bash
/plugin install rails_native_kit@github:cuongnc0211/rails_native_kit
```

## Usage

Skills are invoked automatically by Claude when relevant. You can also invoke them explicitly:

```
/hotwire-native
/kamal
```
